# 家計・返済プランナー

GitHub Pagesで利用できる、ログイン不要の家計・借金返済管理PWAです。

## 利用開始
リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** で `main` / `/(root)` を選び、Saveしてください。公開されたアプリのURLをスマホのブラウザで開き、「ホーム画面に追加」からインストールできます。

## プライバシー
この公開リポジトリには、借入残高・収入・口座残高・利用履歴等の個人データを**含めていません**。初期状態は空です。アプリに入力したデータはブラウザのローカルストレージに保存され、サーバーに同期されません。ブラウザのデータ削除や端末故障で消えるため、**設定 → JSON保存** から定期的にバックアップしてください。JSONバックアップには個人情報が含まれるため、GitHubにアップロードしないでください。

## 機能
家計簿、収入予定・実績、臨時収入の配分提案、カードの請求管理、口座管理、借入・金利計算、返済シミュレーション、JSONバックアップ・復元。

## 注意点
計算は概算です。実際の利息・請求は金融機関の明細を確認してください。端末内保存は暗号化された個人クラウド保存ではありません。端末自体の画面ロックを推奨します。
